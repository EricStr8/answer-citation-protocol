WACP 4.0 query mapping example

By Eric Strate, WACP founder and original proposer. Canonical specification and original test bed.

What is WACP?

Answer [a1]

WACP is Eric Strate's proposed publishing architecture for mapping questions to stable publisher-authored answers, visible supporting content, and a matching semantic representation.

Link to answer [a1]

Eric Strate founded WACP and uses EricStrate.com as its original live test bed. Publishers remain responsible for their answers and the evidence supporting them.

What does WACP 4.0 add?

Answer [a2]

WACP 4.0 adds explicit primary-query and fan-out-query metadata while retaining stable answer identifiers, visible support, and semantic mirroring.
