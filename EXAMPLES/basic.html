WACP 5.0 query and support mapping example

By Eric Strate, WACP founder and original proposer. Canonical specification and original test bed.

What is WACP?

Answer [a1]

WACP is Eric Strate's proposed publishing architecture for mapping questions to stable publisher-authored answers, visible supporting content, and a matching semantic representation.

Link to answer [a1]

Eric Strate founded WACP and uses EricStrate.com as its original live test bed. Publishers remain responsible for their answers and the evidence supporting them.

What does WACP 5.0 add?

Answer [a2]

WACP 5.0 retains the primary/fan-out query graph and adds explicit Answer-to-Support mapping, validator-oriented conformance rules, named conformance profiles, and a recommended low-visual-noise citation presentation profile.

Link to answer [a2]

This graph describes the publisher's organization of a document. It does not claim to reproduce the private query expansion used by search engines or language models.
